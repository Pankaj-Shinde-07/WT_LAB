Student Enrollment with Pure NodeJS Validation

Demonstrating chunked HTTP request stream processing, pure Node.js modular validation, HTTP 400 rejection for malformed data, and persistent JSON storage without framework abstractions.

Course Enrollment Application

All form fields are strictly validated on the Node.js server before acceptance.

⚙️ Node.js Architecture Summary

  • Core HTTP Engine: Built with native http.createServer.
  • Stream Body Parser: Buffers chunked data via req.on('data') and parses on req.on('end').
  • Validation Module: Modular rules in modules/validator.js.
  • Status Codes: Returns 201 Created on success and 400 Bad Request on validation failure.
  • Persistence: Atomic synchronization into data/students.json.
